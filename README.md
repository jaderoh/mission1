## Docker (도커)의 개념

- Docker란 항구 컨테이너에 비유할 수 있습니다.
- 프로그램과 프로그램이 필요한 모든 것을 하나의 박스에 담아서, 어떤 컴퓨터에서든 똑같이 실행되게 해주는 도구입니다.
- (1) Image (이미지) : 설계도
- (2) Container (컨테이너) : 실제로 실행 중인 것
- (3) Dockerfile (레시피) : 이미지를 만들기 위한 레시피
